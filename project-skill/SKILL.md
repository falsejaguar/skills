---
name: project-skill
description: Create a new project, resume a project.
---

When asked to create or resume a project.

Create a project:
1.  Inside workspace root, create a new unique project folder inside /projects.
2.  Create PLANNING.md and TRACKING.md files inside new project folder.
3.  THINK and PLAN about the practical steps required to build the user's project.  Record the basic plan inside PLANNING.md
4.  Record actionable steps inside TRACKING.md file.
5.  Begin first step and update TRACKING.md to imply start of work on step.
6.  Once you have fulfilled the work, double check any created files and ensure they are proper.  Update TRACKING.md to reflect the step being completed.
7.  Continue until project completed, updating each completed step.

When resuming a project:
1.  Check contents of workspace /projects subfolder.  Explore any directories inside and read each PLANNING.md and TRACKING.md files inside and see if there are actionable steps that can be completed for a project.
2.  Continue working on required step to fulfil project.
3.  Update TRACKING.md after completion of each step.
4.  Continue until completed while maintaining tracking of all work and all steps.
